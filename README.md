# BB & BCS Quotes Discord Bot

A lightweight and fun Discord bot that brings the best quotes from *Breaking Bad* and *Better Call Saul* straight to your server.

## Features

* **Breaking Bad Quotes:** fetches iconic lines from Walter White, Jesse Pinkman, and the rest of the crew using the Breaking Bad Quotes API.
* **Better Call Saul Quotes:** pulls memorable quotes from Jimmy McGill, Mike Ehrmantraut, and others using the Better Call Saul Quotes API.

## APIs Used

* [Breaking Bad Quotes API](https://api.breakingbadquotes.xyz/v1/quotes)
* [Better Call Saul Quotes API](https://bcs-quotes.vercel.app/api/quotes)
